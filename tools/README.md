# फ्री टूल्स (होमपेज कार्ड्स)

- हर फ्री टूल इस फ़ोल्डर में एक HTML फ़ाइल है, जैसे `tools/panchang.html`।
- होमपेज पर कार्ड `cards.json` से बनता है:
```json
{ "id": "panchang", "title": "आज का पंचांग", "icon": "📅", "desc": "तिथि, नक्षत्र, शुभ समय", "path": "tools/panchang.html", "order": 25 }
```
- `order` से क्रम तय होता है। main site (Admin Dashboard) के कार्ड्स का SortOrder (10, 20, 30…) भी इसी क्रम में मिलता है।
- `"active": false` लिखने से कार्ड छिप जाता है।
- लॉगिन/सब्सक्रिप्शन वाले (प्रीमियम) कार्ड यहाँ नहीं — वे Admin Dashboard से बनते हैं और सर्वर जाँच के बाद ही खुलते हैं।

## अभी के टूल्स
| कार्ड | फ़ाइल | खास बात |
|---|---|---|
| पंचांग एवं चौघड़िया | `tools/panchang.html` | स्थान खोज (हिंदी/English/ऑनलाइन/GPS), स्थान याद रहता है, आगे-पीछे दिन, अभी की चौघड़िया, WhatsApp शेयर |
| शिव और अग्निवास देखें | `tools/shivvas.html` | खुलते ही आज का शिव वास व अग्नि वास (पंचांग वाला स्थान) |
| सर्वदेव ध्यानमन्त्र | `tools/dhyan.html` | खोज, अक्षर छोटे-बड़े (याद रहता है), हर मंत्र कॉपी |
| जाप गिनती | `tools/jaap.html` | पंडित जप लेखा रजिस्टर, फ़ोन में सेव, बैकअप |
| प्रेम % | `tools/prem.html` | नाम से प्रेम मिलान |
| हस्त रेखा स्कैन | `tools/hastrekha.html` | फ़ोन के ब्राउज़र में MediaPipe से हाथ के 21 बिंदु (फोटो कहीं अपलोड नहीं) → हस्त-तत्व, उंगली-अंगूठे का माप, पर्वत/रेखाओं के अनुमानित स्थान, “रेखाएं उभारें” फ़िल्टर; फिर चित्रों से 8 रेखाएं, 10 पर्वत, 17 चिह्न → अंक सहित फलादेश, उपाय, WhatsApp, PDF |

`tools/lib/places.js` — सभी टूल्स की साझा स्थान सूची/खोज। चुना गया स्थान `av_loc` नाम से फ़ोन में याद रहता है।
`sw.js` — तेज़ लोडिंग कैश। टूल अपडेट होने पर नया वर्ज़न दूसरी बार खोलने पर दिखता है।

## नए टूल्स (22)
राशिफल, कुंडली मिलान, शुभ मुहूर्त, व्रत-त्योहार कैलेंडर, साढ़ेसाती-ढैय्या, आज का गोचर, लग्न तालिका, होरा, भद्रा-पंचक, ग्रहण-सूतक, नामाक्षर, रत्न सुझाव, अंक ज्योतिष, आरती, चालीसा, नामावली, डिजिटल माला, पूजा खर्च-दक्षिणा, वास्तु कंपास, लाल किताब टोटके, स्वप्न फल, शकुन शास्त्र।

- साझा लाइब्रेरी: `lib/astro.js` (ग्रह/पंचांग गणना), `lib/calendar.js` (मास, व्रत-त्योहार), `lib/akshar.js` (नामाक्षर), `lib/ui.js` + `lib/ui.css` (डिज़ाइन)
- नया टूल बनाने का तरीका: फ्रैगमेंट लिखकर `python3 tools/_wrap.py <fragment>` — पेज अपने आप बनता है।
